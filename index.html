🚀 How to start your first HTML code

Step 1: Open Visual Studio Code.

Step 2: Create a new file using Ctrl + N.

Step 3: Save it as index.html using Ctrl + S.

Step 4: Type ! and press Enter to expand the HTML starter template using Emmet.

Step 5: Start writing your code!

YOUR FIRST HTML CODE
<!DOCTYPE html>
<html>
<head>
  <title>My First Website</title>
</head>
<body>
  <h1>Hello World!</h1>
  <p>I am learning to code.</p>
</body>
</html>

02. HTML basics

Learn what the most useful HTML tags do.

Heading

<h1>Hello!</h1>

Creates a heading.

Paragraph

<p>My text</p>

Creates a paragraph.

Button

<button>Click me</button>

Creates a button.

Image

<img src="photo.jpg">

Displays an image.

Link

<a href="https://example.com">Visit</a>

Creates a clickable link.

Division

<div>Content</div>

Groups elements together.

03. CSS tricks

Change colour

color: red;

Changes text colour.

Background

background: black;

Changes background colour.

Rounded corners

border-radius: 15px;

Makes corners rounded.

Spacing

padding: 20px;
margin: 10px;

Controls spacing.

04. JavaScript basics

Variables

let username = "Malik";
let age = 13;

Variables store information.

Functions

function sayHello() {
  alert("Hello!");
}

Functions let you reuse instructions.

Button interaction

<button onclick="sayHello()">
 Click me
</button>

<script>
function sayHello() {
 alert("Hello World!");
}
</script>

This makes a button display a message when clicked.

05. Keyboard shortcuts ⚡

Windows shortcuts for Visual Studio Code. Search for any shortcut below.

Ctrl + ASelect all code

Selects everything in the current editor.

Ctrl + CCopy

Copies selected code.

Ctrl + VPaste

Pastes copied code.

Ctrl + XCut

Cuts selected code.

Ctrl + ZUndo

Reverses your last action.

Ctrl + YRedo

Restores an undone action.

Ctrl + SSave

Saves your current file.

Ctrl + NNew file

Creates a new file.

Ctrl + /Comment

Toggles a line comment.

Ctrl + FFind

Searches for text in your code.

Ctrl + HReplace

Finds and replaces text.

Ctrl + 1Editor group 1

Focuses the first editor group. It does NOT start coding.

Ctrl + 2Editor group 2

Focuses the second editor group.

Ctrl + Shift + PCommand palette

Searches VS Code commands.

Ctrl + `Terminal

Opens or closes the integrated terminal.

Alt + ↑ / ↓Move line

Moves a line up or down.

Ctrl + Shift + KDelete line

Deletes the current line.

Shift + Alt + FFormat code

Formats the document when a formatter is available.

Ctrl + SpaceSuggestions

Shows code completion suggestions.

Ctrl + PQuick open

Quickly opens a file.
